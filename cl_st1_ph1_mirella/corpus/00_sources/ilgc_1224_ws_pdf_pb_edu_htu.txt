How to use this guide

This style guide contains an overview of useful terminology and examples relating to inclusive language. It is structured as follows:

The guide starts with general guidelines for using language inclusively.
The next part of the style guide focuses on identity-based language, including gender-aware language use, language surrounding ability and disability, and language on background, ethnicity, race, nationality, and migration.
The second part of the style guide focuses on theme-based language use, meaning how to use it in emails, official language, and human resources.
A short section on inclusive language in Dutch is presented.
Finally, a glossary and list of further resources conclude the document.

The style guide can be used like a dictionary or grammar tool: search for the language issue you are grappling with in the table of contents and use the style guide to help you. It is always best to ask or look something up rather than to assume!
